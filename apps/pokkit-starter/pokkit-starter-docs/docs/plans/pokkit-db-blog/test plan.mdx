# Test Plan

## Scope

This plan covers required tests for Pokkit Db Blog collection permissions:

Each test is given a tag in the following format. PDB-{COLLECTION}-{ACTION}-{NN} In order to track the tests more easily.

- `BP` — `blogPosts`
- `BPI` — `blogPostImages`

❌ in the spec means the action must be denied; those cases still need tests. Statuses are grouped when behaviour is the same.

---

## blogPosts collection permission tests

### PDB-BP-CREATE-01 — Global Superadmin (approved) can CREATE

Checks that a user with global user permissions role `superadmin` and status `approved` can CREATE a record in the `blogPosts` collection.

### PDB-BP-CREATE-02 — Global Superadmin (pending or blocked) cannot CREATE

Checks that a user with global user permissions role `superadmin` and status `pending` or `blocked` cannot CREATE a record in the `blogPosts` collection.

### PDB-BP-CREATE-03 — Global Admin (approved) can CREATE

Checks that a user with global user permissions role `admin` and status `approved` can CREATE a record in the `blogPosts` collection.

### PDB-BP-CREATE-04 — Global Admin (pending or blocked) cannot CREATE

Checks that a user with global user permissions role `admin` and status `pending` or `blocked` cannot CREATE a record in the `blogPosts` collection.

### PDB-BP-CREATE-05 — Global Standard (approved, pending or blocked) cannot CREATE

Checks that a user with global user permissions role `standard` cannot CREATE a record in the `blogPosts` collection - it is not relevant whether the user is `pending`, `approved`, or `blocked`.
