# Test Plan

## Scope

Required tests for syncing PocketBase config with:

- Collections ↔ `pb_config/collections.json`
- Settings ↔ `pb_config/settings.json`
- Secrets ↔ `pb_config/secrets.json`

---

## Collections

### PDBCS-COL-01 — Valid collections file imports on startup

Checks that when `pb_config/collections.json` exists and is valid, collections are imported from the collections file.

### PDBCS-COL-02 — Invalid collections file fails on startup

Checks that when `pb_config/collections.json` exists but is not valid collection data, startup throws an error.

### PDBCS-COL-03 — Missing collections file exists once onServe finishes

Checks that when `pb_config/collections.json` does not exist, the plugin creates it when onServe finishes.

### PDBCS-COL-04 — Missing collections file matches database collections once onServe finishes

Checks that when `pb_config/collections.json` does not exist, database collections are left as is - in the state that existed before the plugin was installed (plus \_pb_config_secrets collection) .

### PDBCS-COL-05 — onServe writes collections file when DB differs

Checks that before onServe finishes, if database collections differ from the collections file, the collections file is updated from the database.

### PDBCS-COL-06 — Runtime collection change updates collections file

Checks that a collection create/update/delete after setup writes the current database collections to `pb_config/collections.json`.

### PDBCS-COL-07 — Valid collections file unchanged when already in sync

Checks that when `pb_config/collections.json` exists, is valid, and matches the database, the collections file is left unchanged.

## Secrets

### PDBCS-SEC-01 — Startup merges then clears `_pb_config_secrets`

Checks that on startup the plugin merges `_pb_config_secrets` into the database, then removes the contents of `_pb_config_secrets`.

### PDBCS-SEC-02 — Valid secrets file imports into `_pb_config_secrets`

Checks that when `pb_config/secrets.json` exists and is valid, secrets are imported from the secrets file into `_pb_config_secrets`.

### PDBCS-SEC-03 — Invalid secrets file fails on startup

Checks that when `pb_config/secrets.json` exists but is not valid secrets data, startup throws an error.

### PDBCS-SEC-04 — Missing secrets file leaves `_pb_config_secrets` unchanged

Checks that when `pb_config/secrets.json` does not exist, `_pb_config_secrets` is left as is (after the merge/clear in SEC-01).

### PDBCS-SEC-05 — onServe updates collection from secrets file when they differ

Checks that before onServe finishes, if database secrets differ from the secrets file, `_pb_config_secrets` is updated from the secrets file.

### PDBCS-SEC-06 — Runtime secrets change updates secrets file

Checks that a `_pb_config_secrets` create/update/delete after setup writes the current database secrets to `pb_config/secrets.json`.

### PDBCS-SEC-07 — Valid secrets file unchanged when already in sync

Checks that when `pb_config/secrets.json` exists, is valid, and matches the database (via `_pb_config_secrets`), the secrets file is left unchanged.

### PDBCS-SEC-08 — Incorrect `_pb_config_secrets` collection is overwritten

Checks that when an incorrect `_pb_config_secrets` collection exists in the database, it is overwritten with the correct collection.
