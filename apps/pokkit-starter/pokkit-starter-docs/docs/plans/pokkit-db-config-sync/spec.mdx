# Spec

## Overview

The overview can be found [here](./index.mdx).

## Collections

### On startup

| Condition                  | Action                               |
| -------------------------- | ------------------------------------ |
| File exists and is valid   | Import collections from file         |
| File exists and is invalid | Throw error                          |
| File does not exist        | Leave database collections unchanged |

### Before onServe finishes

| Condition                             | Action                             |
| ------------------------------------- | ---------------------------------- |
| Database collections match file       | Leave file unchanged               |
| Database collections differ from file | Write database collections to file |

### At runtime

| Condition                          | Action                             |
| ---------------------------------- | ---------------------------------- |
| Collections change in the database | Write database collections to file |

## Secrets

### On startup

| Condition                  | Action                                                                        |
| -------------------------- | ----------------------------------------------------------------------------- |
| Always                     | Merge `_pb_config_secrets` into the database, then clear `_pb_config_secrets` |
| File exists and is valid   | Import secrets from file into `_pb_config_secrets`                            |
| File exists and is invalid | Throw error                                                                   |
| File does not exist        | Leave `_pb_config_secrets` unchanged                                          |

### Before onServe finishes

| Condition                         | Action                                |
| --------------------------------- | ------------------------------------- |
| Database secrets match file       | Leave `_pb_config_secrets` unchanged  |
| Database secrets differ from file | Update `_pb_config_secrets` from file |

### At runtime

| Condition                      | Action                                             |
| ------------------------------ | -------------------------------------------------- |
| Secrets change in the database | Write database secrets to `pb_config/secrets.json` |
