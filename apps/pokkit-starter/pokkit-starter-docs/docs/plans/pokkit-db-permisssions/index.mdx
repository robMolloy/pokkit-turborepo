# Pokkit Db Permissions

## Overview

Pokkit Db Permissions is a PocketBase plugin that makes CRUD access control easier. It keeps the stock `users` collection and adds three supporting collections, plus a reusable PocketBase API rule syntax other collections can reference.

- `globalUserPermissions` — system-wide role and status per user (`standard` | `admin` | `superadmin`; `pending` | `approved` | `blocked`)
- `organisations` — named groups for organisation-scoped access
- `organisationUserPermissions` — membership of a user in an organisation (`standard` | `admin`, same status values; unique per user/org)


## How it works

For the three supporting collections, that are initialized on install, only superadmins can manage global, organisation, and organisation user permissions.

## Using pokkit db permissions

Once set up a simple rule template is available to use in other collections as follows;

```
// Approved global superadmins only
@request.auth.id != "" 
&& @collection.globalUserPermissions.userId ?= @request.auth.id 
&& @collection.globalUserPermissions.role ?= "superadmin" 
&& @collection.globalUserPermissions.status ?= "approved"

// Approved global superadmins or admins only
@request.auth.id != "" 
&& @collection.globalUserPermissions.userId ?= @request.auth.id 
&& (
  @collection.globalUserPermissions.role ?= "superadmin" 
  || @collection.globalUserPermissions.role ?= "admin"
) 
&& @collection.globalUserPermissions.status ?= "approved"
```
