# Pokkit Permissions

## Overview

Pokkit Permissions is a PocketBase plugin that makes CRUD access control easier. It keeps the stock `users` collection and adds three supporting collections, plus a reusable PocketBase API rule syntax other collections can reference.

- `globalUserPermissions` — system-wide role and status per user (`standard` | `admin` | `superadmin`; `pending` | `approved` | `blocked`)
- `organisations` — named groups for organisation-scoped access
- `organisationUserPermissions` — membership of a user in an organisation (`standard` | `admin`, same status values; unique per user/org)

Only `approved` records grant powers. Global and organisation permissions are separate: org admin ≠ global admin ≠ superadmin.

## How it works

On install the plugin bootstraps the three collections (import from `pb_config/collections.json`, or create them and write the file). The first created user is provisioned as an approved `superadmin`. Approved global admins can create organisations and are provisioned as that org's admin; superadmins can manage any org/membership and others' global permissions.

Other collections gate list / view / create / update / delete with PocketBase API rules that query these permission records via a documented `@collection.*` syntax. See the [spec](./spec) for fields, roles, bootstrap rules, and rule patterns.
